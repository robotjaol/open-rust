# Packaging

## Linux (validated)

```bash
./scripts/package-linux.sh        # needs dpkg-deb
```

Produces `dist/open-rust-<version>-linux-<arch>.tar.gz` and `dist/open-rust_<version>_<arch>.deb`
(binary, desktop entry, icon, licences). Packages are unsigned.

## Windows and macOS (configured, not built)

`Packager.toml` configures cargo-packager (NSIS `.exe`, `.dmg`):

```bash
cargo install cargo-packager --locked
cargo packager --release
```

## Signing and notarization (not performed)

- Windows: sign with an Authenticode certificate (for example with `signtool`) in CI using secrets.
- macOS: sign with a Developer ID Application certificate, then notarize with Apple's `notarytool`.
- Linux: sign packages or publish checksums (`SHA256SUMS.txt` is generated by the release workflow).

Never commit certificates or passwords.
