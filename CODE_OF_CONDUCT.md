# Code of Conduct

This project follows the spirit of the Contributor Covenant, version 2.1
(https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standard

Be respectful, assume good faith, and keep feedback about the work, not the person.
Harassment, discrimination, personal attacks, doxxing and unwelcome sexual attention are
not acceptable in issues, pull requests, discussions or any other project space.

## Enforcement

Maintainers may edit or remove comments, close threads, and block people who break this
standard. Report a problem privately through a GitHub security advisory draft or by
contacting the maintainer (robotjaol) on GitHub. Reports are handled in confidence.
